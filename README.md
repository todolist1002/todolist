# 📋 TaskFlow - 스마트 To-Do List & 생산성 대시보드

![TaskFlow Header](https://img.shields.io/badge/TaskFlow-v1.0.0-6366f1?style=for-the-badge&logo=appveyor)
![License](https://img.shields.io/badge/License-MIT-10b981?style=for-the-badge)

**TaskFlow**는 직관적이고 세련된 다크 글래스모피즘(Glassmorphism) 테마 기반의 To-Do List 웹 애플리케이션입니다.  
사용자의 일상 업무, 공부, 습관 및 프로젝트 달성률을 한눈에 파악하고 효율적으로 관리할 수 있습니다.

---

## ✨ 주요 기능 (Key Features)

- 📋 **할 일 관리 (CRUD)**: 빠른 생성 (Enter 키), 상세 메모, 세부 체크리스트(Subtasks), 복사 및 삭제
- 🔥 **우선순위 & 마감일**: 높음/보통/낮음 선택 및 오늘 마감/마감 초과 자동 강조
- 🏷️ **커스텀 카테고리**: 업무, 개인, 공부, 건강 등 기본 카테고리 및 사용자 맞춤 카테고리 추가 (이모지 & 색상 선택)
- 🔍 **검색 & 필터링**: 실시간 키워드 검색 (단축키 `/`), 상태별 탭 필터 (전체/진행 중/완료/오늘 마감/중요 ⭐️), 4가지 정렬
- 📊 **생산성 통계 & 리포트**: 원형 달성률 차트 (Donut SVG), 연속 달성 스트릭(Streak), 카테고리/우선순위 분포
- 🌙 **테마 & 사운드**: 다크 모드 / 라이트 모드 전환, 완료 체크 시 Web Audio API 알림 효과음
- 💾 **데이터 지속성 & 백업**: `LocalStorage` 자동 저장, JSON 파일 내보내기/불러오기 지원

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism & CSS Variables), Modern JavaScript (ES6+)
- **Icons & Fonts**: FontAwesome 6, Google Fonts (Plus Jakarta Sans, Noto Sans KR)
- **Audio & Storage**: Web Audio API, Browser LocalStorage API

---

## 🚀 시작하기 (Getting Started)

별도의 설치 과정 없이 브라우저에서 `index.html` 파일을 열어 바로 사용하실 수 있습니다.

```bash
# 저장소 클론
git clone https://github.com/xodbs4898-byte/todolist.git

# 폴더 이동
cd todolist

# index.html 실행
```
